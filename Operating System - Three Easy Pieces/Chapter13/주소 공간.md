## 용어

| 용어 | 정의 |
| ---- | ---- |
| 가상 메모리 (virtual memory) | 보조 기억장치를 주 기억장치 인 것 처럼 사용하는 기법 |
| 메모리 가상화 (Memory Virtualization) | 프로그램이 인지하는 주소와 실제 정보가 위치하는 주소 공간을 서로 다르게 하여 직접 사용하는 듯한 환상을 제공하는 기술 |
| 가상 주소 | 논리적인 주소, 프로세스 입장에서의 메모리 주소 |
| 물리 주소 | 물리적인 주소, 실제 하드웨어의 주소 |
| MMU (Memory Management Unit) | CPU가 생성한 가상 주소를 물리 주소로 변환하는 하드웨어 장치 |


## 서론
멀티프로그래밍의 활성화에 따라 시분할 시스템이 도입되어 동시에 많은 프로세스가 실행되기 시작하였다.
이에 따라 메모리 점유 방식에 문제가 제기되었으며, 

가상메모리 기법을 사용해 프로세스가 메모리를 독점하고 있다는 환상을 제공한다.
실제로는 물리 메모리를 공유하지만, 각 프로세스는 다른 프로세스의 메모리 구조를 직접 인식하지 못한다.

## 고립의 원칙
두 개체가 서로 적절하게 고립된 경우 한 개체가 실패해도 상대 개체에 아무 옇양을 주지 않는다.

## VM의 주요 목표
1. 투명성
	실행중인 프로그램이 가상 메모리의 존재를 인지하지 못해야 함
2. 효율성
	시간과 공간 측면에서 효율적이여야 한다.
3. 보호
	운영체제 스스로와 프로세스는 다른 프로세스로 부터 보호되어야 한다.

## VM
* 메모리가 프로세스 전용 공간이라는 환상을 프로그램에게 제공해야한다.
* 운영체제는 하드웨어의 도움을 받아 가상메모리를 물리주소로 변환한다.
