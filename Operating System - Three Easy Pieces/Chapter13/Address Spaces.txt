메모리 가상화	프로그램이 인지하는 주소와 실제 정보가 위치하는 주소를 서로 다르게 하는 기술
가상 주소	프로그램이 인지하는 주소
물리 주소	정보가 실제로 적재되는 메모리 주소
virtual memmory

고립의 원칙 : 두 개체가 서로 적절하게 고립된 경우 한 개체가 실패해도 상대 개체에 아무 영향을 주지 않는다.

가상 메모리 시스템의 주요 목표
투명성		실행중인 프로그램이 가상 메모리의 존재를 인지 하지 못해야 함
효율성		시간과 공간 측면에서 효율적이여야 한다.
보호		운영체제 스로와 프로세스는 다른 프로세스로 부터 보호되어야한다. (고립되어야 한다.)


virtual memory
메모리가 프로세스 전용 공간이라는 환상을 프로그램에게 제공해야한다.
운영체제는 하드웨어의 도움을 받아 가상메모리를 물리주소로 변환한다.
