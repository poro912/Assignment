hardware based adress translation 하드웨어 기반 주소 변환 (주소변환)
가상 주소 에서 물리 주소로 변환 하는 기술 


프로그램의 모든 메모리 참조를 실제 메모리 위치로 재지정 하기 위해서는 하드웨어가 주소를 변환 한다.


프로그램이 자신의 전용 메모리를 소유하고, 그 안에 자신의 코드와 데이터가 있다는 환상을 만듦

이에 따른 최초 메모리 적재 방식 아이디어에 대해 학습


동적(하드웨어 기반) 재배치

물리 주소 = 가상주소 + 베이스
physical address = virtual address + base

정적 재배치
	하드웨어 지원이 제공되기 전, 시스템 소프트웨어만으로 재배치를 수행하였음
	로더는 명령어의 모든 주소를 3000씩 이동한 주소로 다시 작성하였음
	문제
		보호 기능이 없어 다른 프로세스나 운영체제의 메모리에 접근 가능했음
		보호를 위해서는 하드웨어 지원이 필요하다
		한번 배치되면 재배치가 어렵다.

동적 재배치
	바운스 레지스터는 16KB로 설정된다.
	변환 결과가 바운스 레지스터를 넘어가거나 음수라면 예외를 발생시키고 종료된다.


바운스 레지스터의 두 가지 방식
	주소 공간의 크기를 지정
		하드웨어가 가상 주소를 베이스 레지스터에 더하기 전에 바운드 레지스터와 비교
		VA < bound
	주소 공간의 마지막 물리주소 저장
		베이스 레지스터를 더하고 그 결과가 바운드 안에 있는지 검사
		base + VA < bound
