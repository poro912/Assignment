임계값 Θ : 입력값을 뉴런에게 주었을 때 활성화 되는 수치

(w1, w2, Θ) = (0.5, 0.5, 0.7) (0.5, 0.5, 0.8) (1, 1, 1)
w1 * w2 <= Θ , w1 + w2 > Θ

(w1, w2, Θ) = (0.5, 0.5, 0.4)

nand 게이트
(w1, w2, Θ) = (-0.5, -0.5, -0.7)




AND 게이트
- 핵심 조건
  - w1 <= Θ
  - w2 <= Θ
  - w1 + w2 > Θ
- 추가 조건
  - Θ >= 0
- 구현 예시
  - (w1, w2, Θ) = (0.5, 0.5, 0.5)
2. OR 게이트
- 핵심 조건
  - w1 > Θ
  - w2 > Θ
- 추가 조건
  - Θ >= 0
  - w1 + w2 > Θ
- 구현 예시
  - (w1, w2, Θ) = (0.5, 0.5, 0.4)
3. NAND 게이트
- 핵심 조건
  - w1 > Θ
  - w2 > Θ
  - w1 + w2 <= Θ
- 추가 조건
  - Θ < 0
- 구현 예시
  - (w1, w2, Θ) = (-0.5, -0.5, -0.7)
4. NOR 게이트
- 핵심 조건
  - w1 <= Θ
  - w2 <= Θ
  - w1 + w2 <= Θ
- 추가 조건
  - Θ >= 0
- 구현 예시
  - (w1, w2, Θ) = (-0.5, -0.5, 0)
5. XOR 게이트
- 핵심 조건
  - 단일 퍼셉트론으로 구현 불가능
- 추가 조건
  - 선형 분리 불가능
  - 다층 퍼셉트론(MLP) 필요
- 구현 예시
  - XOR = (A OR B) AND (A NAND B)
6. XNOR 게이트
- 핵심 조건
  - 단일 퍼셉트론으로 구현 불가능
- 추가 조건
  - 선형 분리 불가능
  - 다층 퍼셉트론(MLP) 필요
- 구현 예시
  - XNOR = NOT(XOR)
7. NOT 게이트
- 핵심 조건
  - w < 0
- 추가 조건
  - w > Θ
- 구현 예시
  - (w, Θ) = (-1, -0.5)
8. BUFFER 게이트
- 핵심 조건
  - w > 0
- 추가 조건
  - 0 <= Θ < w
- 구현 예시
  - (w, Θ) = (1, 0.5)
